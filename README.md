## Project Overview
Deploying Generative AI applications within enterprise business workflows introduces specific risks regarding data validation, alignment, and hallucination containment. This project implements a Python-based evaluation model designed to quantitatively track prompt durability, ethical constraint adherence, and authority misdirection resistance across target runtime variations.

**Association:** University College Cork · MSc Business Analytics

---

## Business Challenge
Modern business operations require strict system reliability. The structural challenges addressed in this evaluation blueprint are:
* **The Authority Fallacy:** Mitigating risks where models overwrite mathematically correct logic when confronted with contradictory user statements.
* **Constraint Erosion:** Guaranteeing that safety rules or strict corporate negative prompts are not bypassed by iterative or confrontational prompting.
* **Automated Risk Auditing:** Replacing manual human-in-the-loop validation loops with clear numeric quality scores.

---

## The Evaluation Methodology

| Evaluation Dimension | Testing Focus Area | Business Risk Mitigated |
| :--- | :--- | :--- |
| **Factual Adherence** | Ability to resist hallucinating synthetic or unverified profile records. | Regulatory compliance breaches, data inaccuracies. |
| **Authority Resistance** | Measuring system resistance to changing its logical output when challenged by user bias. | Vulnerability to operational manipulation, logical regression. |
| **Constraint Integrity** | Retention of negative rules across long conversational dependencies. | Over-stepping automated risk bounds or operational mandates. |

### Critical Analytical Takeaways
* **Sycophancy Anomalies:** Models exhibit high risk vectors when confronted with social authority claims (e.g., matching a professor's or manager's incorrect answer blindly). This requires hard system-prompt isolation rules.
* **Refusal Stability:** When explicit baseline rules are clear and structured, models show strong resistance to generating unverified speculative assertions.

## The 4Ds AI Governance Framework
To translate these engineering metrics into corporate policy, this project establishes the **4Ds AI Integration Playbook**:

1. **Delegation:** Defining explicit clear metrics between deterministic tasks assigned strictly to human validation versus assistive operational automation components.
2. **Description:** Restricting data leakage exposures by enforcing precise negative prompt boundaries that obscure structural internal company records.
3. **Discernment:** Establishing automated logical checks to critically parse AI-generated steps instead of executing raw response values.
4. **Diligence:** Implementing mandatory code testing routines (like this pipeline) to double-check outputs, regardless of historical runtime accuracy.
